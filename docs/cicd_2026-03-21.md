## VM4 Delivery Model

`deploy-vm4` is now the canonical carrier for:

- web/API runtime
- OIDC-aware auth runtime
- Keycloak deployment
- Vault deployment
- governance APIs
- `/app/*` operator shell updates
- access-plane guardrails

Its quality model is split intentionally:

- full backend suite in `Validate Main`
- remote-compatible backend regression subset in `deploy/vm4_enterprise_foundation_deploy.py`
- live acceptance in `deploy/vm4_enterprise_foundation_smoke.py`

This keeps standard rollout reproducible on VM4 without duplicating every CI-only unittest assumption inside the live host environment.
